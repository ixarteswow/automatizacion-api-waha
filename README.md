# Automatizacion API

Servicio backend para automatizar la gestion de leads y flujos de mensajeria. Este repositorio contiene el codigo fuente principal y una configuracion de entorno de ejemplo.

## Contenido
- API y logica de negocio en `src/`.
- Variables de entorno de ejemplo en `.env.example`.
- Dependencias en `requirements.txt`.

## Uso basico
1. Copia `.env.example` a `.env` y ajusta las variables segun tu entorno.
2. Instala dependencias con `pip install -r requirements.txt`.
3. Ejecuta la API con `uvicorn` o el comando que uses habitualmente.
